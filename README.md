## Descripción

Plataforma de asesoría previsional que permite a asesores gestionar clientes y simulaciones de ahorro AFP, con proyecciones personalizadas y generación de documentos.

## Stack

- Next.js 16 + React 19 + TypeScript
- PostgreSQL + Prisma ORM (Supabase)
- Supabase Auth (JWT)
- @react-pdf/renderer
- Zod
- Desplegado en Vercel + Supabase

## Funcionalidades

- 🔐 Autenticación segura con Supabase Auth
- 📊 Simulador previsional con motor de cálculo AFP
- 👥 Gestión de clientes con historial de simulaciones
- 📄 Exportación de simulaciones en PDF
- 📈 Proyecciones personalizadas de ahorro
